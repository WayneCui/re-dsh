# 角色定义 — harness-spine 双书漫画宇宙

**画风**：minimalist 四格（极简线条 + 少量点缀色），纸面底色 `#FDF6EC`，线条 `#1F2937`
**实现**：由 `../comic-cast/comic-gen.ts` 程序化绘制（SVG），角色由固定组件构成，保证全书一致

---

## 角色 1：小壳（读者化身 / learner）

- **形象**：年轻工程师，橙色连帽衫（`#F59E0B`），圆框眼镜，波波头
- **性格**：好奇、爱提问、替读者说出「等等，为什么？」
- **出现**：全书每一章，通常在提问或动手

## 角色 2：脊先生（导师 / mentor）

- **形象**：资深架构师，灰蓝马甲（`#64748B`），平头短须，常持蓝图
- **性格**：冷静、点到为止，金句制造机
- **口头禅**：「循环只是皮带。」

## 角色 3：阿粗（挑战者 / challenge，代表朴素设计）

- **形象**：急性子黑客，绿 T 恤（`#10B981`），刺猬头，体格壮
- **性格**：永远相信「一个全局变量就够了」，负责当场翻车
- **出现**：每章的「最省事做法」人格化

## 角色 4：账房先生（agent-loop 的化身 / support）

- **形象**：藏蓝长衫（`#1E3A8A`），瓜皮帽，八字须，永远捧着装订账本
- **行为规则**：每天早晨把账本大声读给客人听（derive-messages）；可以转述、不许伪造（resume 契约）
- **出现**：第 2/3/7/9/10 章及 Build 书 Step 1/2/3/10/11

## 角色 5：客人（LLM 模型的化身）

- **形象**：紫围巾（`#8B5CF6`），长发，双手永远背在身后
- **行为规则**：只说话（text / tool-call），不下场、不记账、不挑房间

## 角色 6：门房（host 服务的化身）

- **形象**：红色制服帽（`#DC2626`），常年做「拦人」手势，守着唯一一扇门

## 角色 7：前台员（session/llm 共享前台）

- **形象**：青色马甲（`#0D9488`），发髻，柜台后办理共享业务

---

## 道具语汇（全书统一）

| 道具 | 含义 |
|---|---|
| 装订账本（米黄 `#FEF3C7`） | session 事件日志，只增不改 |
| 影印机 | `snapshot-json-map` 快照 |
| 一扇门 | host，唯一 I/O 出口 |
| 安检通道三岗 + 大喇叭 | tools pre/execute/post + `tools-result` |
| 「仅此一次」印章 | approval allowed-once |
| 空座位挂牌 | `'unavailable`（缺席即拒绝） |
| 信封 ×3 | inbox：followup / steer / inject |
| 隔音墙 / 钥匙 | scope 隔离与事件路由 |
| 赛道检查点 + 小旗 | 取消检查点 + cancel-requested |
| 虚线鬼魂 | 日志里「没写完的故事」 |
| 四层蛋糕 | bundle → profile → home → `--patch` |
| 吊车换人 | 热替换 reload |
